🍽️ Dapur Ina Aina

Sistem Terkomputerisasi Restoran — Pemesanan, Transaksi, Stok & Laporan

Deskripsi Project

Sistem ini dibangun untuk membantu operasional Restoran "Dapur Ina Aina", mencakup pemesanan pelanggan, transaksi penjualan, informasi stok barang, hingga laporan penjualan berkala.

Fitur Utama

  • Pemesanan pelanggan & billing / tagihan
  • Pembayaran: tunai, debit, kartu kredit, QRIS
  • Manajemen stok makanan & minuman (tersedia/habis)
  • Laporan penjualan per minggu / per bulan
  • 3 kategori produk: makanan utama, appetizer, minuman

Teknologi

PHP MySQL Arsitektur 3-Tier

Aktor Sistem

  • Pelanggan
  • Kasir
  • Administrator

Catatan

Project ini menggunakan PHP & MySQL sehingga tidak dapat dijalankan langsung di GitHub Pages (hosting statis). Source code lengkap tersedia di repository ini.

Dibuat sebagai tugas mata kuliah Pemrograman Muda
